Проверка OCR…

Файл передаётся на сервер по HTTPS для временного анализа и не сохраняется в каталоге сайта. Сервер может использовать временное хранилище. OCR до трёх страниц выполняется на сервере (файлы до 25 МБ). При сложных сканах обработка может быть длительной. Не загружайте конфиденциальные документы без разрешения.

Если найденный PDF не читается сервером: нажмите «Открыть PDF» в результатах, сохраните файл на компьютер и загрузите сюда. PDF будет прочитан со стороны браузера, даже если сайт производителя блокирует сервер.
