Документы качества — лёгкое исправление 8.2 для бесплатного Render

Ошибка в вашем логе: PermissionError: [Errno 13] Permission denied: /usr/local/lib/python3.11/site-packages/rapidocr/models/ch_PP-OCRv4_det_mobile.onnx.

Причина: предыдущий Dockerfile запускал warm_ocr.py после USER appuser. При сборке RapidOCR пытался загрузить модель в системный каталог пакета, закрытый для непривилегированного пользователя.

ИСПРАВЛЕНИЕ: только Dockerfile. Теперь прогрев RapidOCR выполняется при сборке Docker до USER appuser. Загруженные модели сохраняются в образе; после этого веб-приложение запускается с обычными ограниченными правами. При сборке проверяется, что минимум две ONNX-модели, включая кириллическую, существуют и доступны на чтение.

На работающем сайте ничего не надо устанавливать. Дополнительные API и платные сервисы не используются. Библиотеки и количество моделей не менялись.

КАК ОБНОВИТЬ:
1. Откройте существующий репозиторий GitHub.
2. Замените ТОЛЬКО Dockerfile файлом из этого архива (если код сайта соответствует версии 8.1).
3. Commit changes.
4. Render → ваш Web Service → Manual Deploy → Clear build cache & deploy (или Deploy latest commit; если уже идёт автодеплой, дождитесь результата).
5. Если сборка успешно завершится, откройте адрес вашего сайта, затем /health, загрузите пробный PDF.

Важно: это исправляет конкретный PermissionError, показанный в логе. Настоящую Docker-сборку и OCR-модель в этой среде запустить не удалось, поэтому не следует считать все последующие ошибки исключёнными. На Free планах Render есть ограничения RAM/CPU, а моделей никто не гарантирует качество распознавания каждого реального документа.
