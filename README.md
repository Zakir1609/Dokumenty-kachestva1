# Документы качества 5.0 — онлайн-поиск проверенных PDF

Сайт запускается на сервере. Пользователям достаточно открыть публичный URL в браузере; Python на их компьютерах не требуется.

## Что изменено в версии 5.0

1. **Не показываются битые ссылки:** результаты поиска попадают в таблицу только после успешной загрузки и открытия PDF через PyMuPDF. Недоступные URL, HTML-страницы вместо PDF, 403/404, тайм-ауты, повреждённые файлы исключаются.
2. **Серверное OCR:** Docker ставит Tesseract с русским (`rus`) и английским (`eng`) языками. Изображения страниц формируются с повышенным разрешением (по умолчанию 170 DPI), используется `psm 3`, при малом количестве текста — `psm 6`. Время на страницу увеличено до 75 секунд. Ошибки OCR больше не скрываются под названием типа исключения.
3. **Проверка OCR:** индикатор на сайте использует фактическую самопроверку Tesseract; `/health` показывает результат проверки OCR.
4. **Скачивание через сайт:** кнопка «Скачать проверенный PDF» повторно скачивает PDF с сервера, если прямой URL не открывается в браузере.
5. **Карточка и Excel:** реквизиты заполняются только по прочитанному тексту; неподтверждённые поля остаются пустыми. Скан без распознанного текста помечается отдельно.

При неудачной загрузке файла сайт **не покажет его в результатах**, даже если поисковая система ссылается на него. Это означает, что результатов может стать меньше. Успешная загрузка PDF не подтверждает подлинность, действительность или связь с фактической партией продукции. Сайт не обращается напрямую к реестрам Росаккредитации для юридической проверки.

## Публикация обновления на Render

**Важно: заменить все файлы проекта**, а не только `app.py`. Особенно важны `Dockerfile`, `requirements.txt`, `templates/index.html`.

1. Распакуйте архив, загрузите его содержимое в существующий GitHub-репозиторий вместо старой версии.
2. Убедитесь, что `Dockerfile` лежит в корне репозитория, а страница — в `templates/index.html`.
3. Render → ваш Web Service → Settings → Build & Deploy. Используйте окружение **Docker**. Запустите **Manual Deploy → Deploy latest commit**, если автоматическое развёртывание не сработало.
4. После публикации откройте `https://АДРЕС-ВАШЕГО-САЙТА/health`. Должно быть `"service":"quality-docs-online-v5"` и `"ocr":{"ready":true,...}`.
5. Перезагрузите страницу сайта без кэша: `Ctrl+F5`. Попробуйте **загрузку PDF** и **интернет-поиск**.

Если в `/health` `ocr.ready=false`, причина указана в `ocr.message`; по ней следует проверять Docker-сборку Render. Убедитесь, что Render не настроен на обычный Python-runtime: пакеты Tesseract ставятся именно Docker-сборкой. В логах Render также есть текст ошибки Tesseract.

## Ограничения и предупреждения

- В поиске автоматически выполняется OCR для первых трёх подтверждённых доступных сканов, другие сканы можно обработать кнопкой «Повторно прочитать PDF» или загрузить файл вручную. Для загрузки сканов OCR выполняется автоматически (до 3 страниц).
- Ограничение файла: 25 МБ; до 200 страниц PDF. Полный текст читается до первых 6 страниц, OCR — до первых 3 страниц. Поэтому реквизиты дальше этой границы могут не попасть в результат.
- Структура сертификатов и паспортов различается. Реквизит, который OCR распознал с ошибкой, может не извлечься. Не считайте результат юридической экспертизой и вручную сверяйте критические поля.
- Сайты с CAPTCHA, ограничением доступа или блокировками облачных адресов могут не отдать PDF — **такие результаты отсекаются**. Доступность ссылки может измениться после поиска.
- Бесплатный поисковый механизм `ddgs` не гарантирует выдачу при блокировке поисковой системы. Можно добавить `BRAVE_SEARCH_API_KEY` как переменную среды для отдельного поиска, если провайдером предоставлен ключ.
- Файлы загружаются на сервер для анализа (без постоянной записи в каталог сайта); не передавайте конфиденциальные файлы без разрешения.

## Тесты

На окружении с установленными Python-зависимостями `python -m unittest discover -s tests -v` проверяет API и парсеры. Отдельно `python tests/offline_smoke.py` проверяет распознавание PDF с текстовым слоем и с настоящим изображением, а также отбрасывание недоступных URL (через тестовые имитаторы сети).

Команды для диагностики Docker-контейнера:

```bash
tesseract --list-langs
python -c "import app; print(app.tesseract_status())"
```

Настройки по умолчанию: `OCR_DPI=170`, `OCR_PAGE_TIMEOUT=75` секунд на страницу, `PORT=10000`.
