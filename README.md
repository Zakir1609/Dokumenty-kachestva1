# Документы качества 9.0 — исправление поиска на Render Free

## Что исправлено

Предыдущий `perform_search()` полностью удалял найденные поисковиком ссылки, если сервер Render не мог получить оригинальный PDF. Ошибки 403/429/timeout и 404 ошибочно приводили к одной и той же пустой выдаче. Теперь статусы разделены.

- Проверенные и прочитанные сертификаты показываются в таблице из **4 столбцов**: наименование материала, номер документа (либо б/н), дата/период, производитель.
- PDF, найденные в интернете, но недоступные именно серверу, показываются отдельно как **непроверенные ссылки**. Это не подтверждение действительности документа и не гарантия, что ссылка откроется в браузере.
- Ссылки с подтверждённой HTTP 404/410 исключаются.
- Каталоги исключаются из автоматической проверки раньше.
- Поиск использует два разных запроса и запасные поисковые источники. Второй запрос может находить сертификаты для диапазона диаметров.
- Файлы PDF временно сохраняются на диске Render, а не копятся целиком в памяти между запросами (лимит временного хранилища 150 МБ, срок хранения 40 минут).
- **Нет новых библиотек, моделей, сервисов или API-ключей**. RapidOCR прежний, не требует платы за распознавание.

## Как установить на действующий сайт версии 8.3

1. В репозитории GitHub замените **только** `app.py` и `templates/index.html` из папки `templates`.
2. Сохраните изменения (`Commit changes`).
3. В Render дождитесь успешного развёртывания (`Live`).
4. Откройте `https://адрес-вашего-сайта/health`: версия должна быть `quality-docs-v9-source-visibility`.
5. Обновите страницу Ctrl+F5.

Версии `Dockerfile`, `requirements.txt`, `local_ocr.py` менять не нужно.

## Что означают результаты

- **Результаты: N** — документы, которые сервер прочитал и отнёс к запросу; реквизиты следует сверить с оригиналом.
- **Найденные ссылки, которые сервер не смог подтвердить: N** — поисковая система нашла адреса, но Render не смог прочитать/подтвердить PDF. Можно открыть исходную ссылку через браузер, скачать и загрузить PDF вручную.
- **Удалённая ссылка (404/410)** — результат исключён, поскольку сервер получил конкретный код отсутствия страницы.
- **Доступ ограничен (403/429)** — это НЕ доказательство отсутствия файла: сайт может блокировать облачный сервер.

## Ограничения

Эта версия устраняет логическую ошибку, скрывавшую все найденные ссылки, **но не обходит ограничения сайтов производителей**. Бесплатный автоматический интернет-поиск на общих IP облачного провайдера не гарантирован, поскольку внешние поисковые сервисы могут ограничивать запросы. Если сайт открылся в вашем браузере, а Render не смог скачать документ, без ручной загрузки четыре реквизита из этого файла извлечь невозможно.

## Проверки

Запуск `python tests/check_v9.py` (в окружении с установленными зависимостями) проверяет обработку настоящего текстового PDF, ошибки 403/404/410/429/timeout, сохранение ссылок при 12 тайм-аутах, два поисковых запроса и HTML. Реальное развёртывание на вашем Render из этой среды проверить нельзя.
