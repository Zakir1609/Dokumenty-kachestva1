ДОКУМЕНТЫ КАЧЕСТВА — ОНЛАЙН-ВЕРСИЯ
====================================

Цель: открыть сайт с любого компьютера без Python и BAT-файлов.

ОДНОРАЗОВАЯ ПУБЛИКАЦИЯ В БРАУЗЕРЕ

1. Перейдите на https://github.com/new
   Создайте новый репозиторий dokumenty-kachestva.

2. Откройте созданный репозиторий, выберите Add file -> Upload files.
   Загрузите содержимое ЭТОЙ ПАПКИ из архива, не сам ZIP-файл.
   Проверьте, что app.py и Dockerfile находятся в корне репозитория,
   а файл index.html — внутри папки templates.
   Нажмите Commit changes.

3. Перейдите на https://dashboard.render.com/
   Выберите New -> Web Service, подключите GitHub и созданный репозиторий.
   Runtime: Docker. Instance/Plan: Free (если доступен).
   Нажмите Deploy/Create Web Service.

4. После статуса Live скопируйте адрес вида https://ВАШ-СЕРВИС.onrender.com
   Это реальный адрес сайта для работы с любого устройства.
   Его не нужно устанавливать на компьютер.

РЕКОМЕНДУЕТСЯ:
В Render -> Environment создайте SITE_PASSWORD (ваш пароль доступа).
Не добавляйте пароль в GitHub! При отсутствии пароля сайт открыт всем.

ВАЖНО:
Публичный адрес невозможно выдать до публикации приложения в вашем
аккаунте хостинга. При использовании Free сайт может просыпаться около минуты.
