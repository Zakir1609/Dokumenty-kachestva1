ДОКУМЕНТЫ КАЧЕСТВА 5.0 — ОБНОВЛЕНИЕ НА RENDER
====================================================

САЙТ УЖЕ РАБОТАЕТ НА RENDER:
1. Распакуйте ZIP на компьютер.
2. Откройте существующий GitHub-репозиторий сайта.
3. Замените ВСЕ файлы: app.py, Dockerfile, requirements.txt, render.yaml,
   templates/index.html, README.md (другие служебные файлы по необходимости).
   ВАЖНО: Dockerfile обновлён для гарантированной установки русского OCR.
4. Сохраните изменения (Commit changes).
5. Render -> ваш Web Service -> Manual Deploy -> Deploy latest commit.
6. Убедитесь, что сервис использует Docker, а не обычную Python-среду.
7. После статуса Live откройте https://ВАШ-АДРЕС/health.
   В ответе должно быть service: quality-docs-online-v5 и ocr.ready: true.
8. Перезагрузите страницу сайта Ctrl+F5 и проверьте загрузку PDF.

САЙТА ЕЩЁ НЕТ:
1. Откройте https://github.com/new и создайте репозиторий.
2. Загрузите файлы из распакованной папки (в КОРЕНЬ репозитория).
3. Откройте https://dashboard.render.com -> New -> Web Service.
4. Подключите GitHub-репозиторий; выберите Runtime: Docker.
5. Выберите доступный тариф и выполните Deploy.
6. Откройте публичный адрес после появления Live.

ПОИСК:
Теперь показываются только доступные, открываемые сервером PDF.
Битые, заблокированные и HTML-ссылки не выводятся.
Если результат не найден, попробуйте другой ГОСТ/производителя.

РАСПОЗНАВАНИЕ:
Скан распознаёт серверная система Tesseract (rus+eng).
Если скан не распознан, нажмите «Повторно прочитать PDF» или
загрузите его через блок «Проверить загруженный PDF».
Причину ошибки OCR смотрите в «Все сведения о документе».

ЕСЛИ OCR НА RENDER НЕ ГОТОВ:
Проверьте /health и логи Render: после сборки Docker должны быть
установлены пакеты tesseract-ocr, tesseract-ocr-rus, tesseract-ocr-eng.

Для пользователей сайта установка Python и программ не требуется.
Проверка внешних URL проводится при поиске. Сайт не гарантирует, что
файл останется доступен впоследствии и не подтверждает его подлинность.
