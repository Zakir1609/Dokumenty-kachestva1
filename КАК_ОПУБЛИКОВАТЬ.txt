ДОКУМЕНТЫ КАЧЕСТВА 4.0 — ОБНОВЛЕНИЕ СУЩЕСТВУЮЩЕГО САЙТА
================================================================

ЕСЛИ САЙТ УЖЕ РАБОТАЕТ НА RENDER:
1. Распакуйте архив.
2. Откройте прежний репозиторий на GitHub.
3. Замените app.py и templates/index.html; остальные файлы по необходимости.
   ВАЖНО: app.py должен лежать в корне репозитория, index.html — в templates/.
4. Нажмите Commit changes.
5. В Render откройте ваш Web Service. Дождитесь Live для нового Deploy.
   Если он не начался: Manual Deploy -> Deploy latest commit.
6. Обновите сайт с помощью Ctrl + F5. Адрес сайта не изменится.

ЕСЛИ САЙТА ЕЩЁ НЕТ:
1. https://github.com/new -> создайте новый репозиторий.
2. Add file -> Upload files -> загрузите СОДЕРЖИМОЕ распакованной папки.
3. Проверьте наличие app.py, Dockerfile, requirements.txt, папки templates.
4. Commit changes.
5. https://dashboard.render.com/ -> New -> Web Service -> GitHub репозиторий.
6. Runtime Docker; тариф Free (если доступен); запустите Deploy.
7. После Live получите https://адрес-вашего-сервиса.onrender.com.

ЕСЛИ У НАЙДЕННОГО PDF НЕ ЗАПОЛНЕНЫ РЕКВИЗИТЫ:
Откройте ссылку на файл в своём браузере. Сохраните PDF и загрузите
его в блок «Уже есть PDF?». Если PDF — скан, сервер попробует OCR.
Отсутствие сетевого доступа сервера к файлу нельзя исправить кнопкой повтора.

Примечание: сайт запускается на сервере. Python и BAT-файлы для
посетителей НЕ требуются. Код проверен офлайн, реальное подключение
конкретного хостинга к сайтам производителей зависит от сети и самих сайтов.
